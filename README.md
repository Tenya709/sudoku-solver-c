# 数独解答プログラム

## 概要
C言語を使用して作成した、数独パズルを自動で解くプログラムです。

## 使用言語
- C言語

## 使用技術
- 再帰処理
- バックトラッキング

## プログラムの説明
9×9の数独パズルを解くプログラムです。空いているマスに数字を順番に入れ、縦・横・3×3の各ブロック内で数字が重複していないかを確認します。条件を満たさない場合は数字を戻して別の数字を試すバックトラッキングを使用しています。

## 工夫した点
再帰関数を利用して、数字を入れる処理と元に戻す処理を繰り返すことで、数独の解を探索できるようにしました。また、数字の重複を確認することで、条件を満たす数字だけを候補として探索するようにしました。

## 制作を通して学んだこと
再帰処理やバックトラッキングの仕組みを理解し、条件に従って試行錯誤しながら問題を解決する考え方を学びました。
